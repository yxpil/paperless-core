# 30 全功能测试用例清单

## 30.0 使用说明

| 列 | 含义 |
| --- | --- |
| ID | 模块前缀 + 序号，导入用例库时保持稳定，不重用 |
| P | P0 阻断发布 / P1 重要 / P2 一般 |
| 类型 | 功能 / 异常 / 安全 / 性能 / 兼容 |
| 自动化 | A 可自动化；M 需人工或真机 |

执行集：**冒烟集** = 全部 P0（约 60 条，30 分钟）；**回归集** = P0 + P1（约 200 条，2 小时）；**全量集** = 332 条（半天，含真机与压测）。每条用例归属哪个集合、何时触发、失败后如何处理，见 `31_测试集合规划与执行.md`。

判定原则：功能类必须给出「预期」可观察的结果，不接受「正常显示」这类模糊描述。
