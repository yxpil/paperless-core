# 17 UI 设计标准

## 17.1 四条设计原则

| 原则 | 含义 | 反例 |
| --- | --- | --- |
| 克制 | 会议中界面要让位于材料，控制元素不得抢占视觉重心 | 满屏悬浮按钮 |
| 一致 | 六端同一组件同名、同形、同行为 | PC 叫「同屏」，平板叫「投屏」 |
| 可读 | 三米外能看清，弱光下不刺眼 | 深色界面配浅灰字 |
| 可降级 | 能力缺失时界面优雅退化，不弹错误 | 老设备弹「不支持」 |

## 17.2 设计令牌

令牌是六端一致性的技术保证。任何颜色、间距、圆角、时长都必须来自令牌，禁止硬编码。

```json
{
  "color": {
    "bg": { "base": "#0E1116", "raised": "#161B23", "sunken": "#0A0D12" },
    "text": { "primary": "#E8ECF2", "secondary": "#9AA6B6", "disabled": "#5A6472" },
    "brand": { "primary": "#2F6BFF", "hover": "#4A80FF", "pressed": "#2557D6" },
    "state": { "success": "#2FA36B", "warning": "#D98A1F", "danger": "#D94848", "info": "#3B8FD9" },
    "level": { "public": "#5A6472", "internal": "#3B8FD9", "secret": "#D98A1F", "top": "#D94848" },
    "overlay": { "scrim": "rgba(6,9,14,0.56)", "watermark": "rgba(200,214,232,0.14)" }
  },
  "font": {
    "family": { "sans": "PingFang SC, Microsoft YaHei, Noto Sans CJK SC, sans-serif", "mono": "JetBrains Mono, Consolas, monospace" },
    "size": { "xs": 12, "sm": 14, "md": 16, "lg": 20, "xl": 26, "display": 34 },
    "lineHeight": { "tight": 1.25, "normal": 1.6, "loose": 1.8 },
    "weight": { "regular": 400, "medium": 500, "bold": 700 }
  },
  "space": { "u1": 4, "u2": 8, "u3": 12, "u4": 16, "u5": 24, "u6": 32, "u7": 48, "u8": 64 },
  "radius": { "sm": 4, "md": 8, "lg": 12, "pill": 999 },
  "motion": {
    "fast": "120ms cubic-bezier(.2,.8,.3,1)",
    "base": "200ms cubic-bezier(.2,.8,.3,1)",
    "slow": "320ms cubic-bezier(.2,.8,.3,1)"
  },
  "elevation": { "1": "0 1px 2px rgba(0,0,0,.28)", "2": "0 4px 12px rgba(0,0,0,.36)", "3": "0 12px 32px rgba(0,0,0,.44)" }
}
```

会议场景默认深色：会议室的投影与大屏在深色底上对比更好，且不刺眼。阅读模式提供浅色（白天、纸质感），由用户或会场策略决定。

## 17.3 栅格与断点

| 端 | 基准宽度 | 栅格 | 断点 | 安全区 |
| --- | --- | --- | --- | --- |
| PC | 1440 | 12 列 / 24 px 槽 | 1280 / 1600 / 1920 | 24 px |
| 平板 | 1024（横） | 8 列 / 16 px 槽 | 768 / 1024 / 1280 | 16 px |
| 白板 | 3840（4K） | 自由画布 | — | 48 px |
| 一体机 | 1080 × 1920（竖） | 6 列 | — | 24 px |
| 网页 | 1280 | 12 列 | 1024 / 1440 | 24 px |
| TV | 1920 | 8 列 | 1280 / 1920 / 3840 | 96 px（5%） |

TV 的安全区必须留 5%：电视过扫描会裁边，不留边必被切。

## 17.4 字号阶梯

| 用途 | PC | 平板 | 白板 | TV |
| --- | --- | --- | --- | --- |
| 正文 | 16 | 17 | 28 | 28 |
| 材料标题 | 22 | 24 | 44 | 40 |
| 按钮文字 | 14 | 15 | 24 | 24 |
| 辅助信息 | 12 | 13 | 20 | 20 |
| 水印 | 12 | 12 | 18 | 18 |

白板与 TV 不是简单放大，而是重新排版：TV 禁止长段落，材料必须分页；白板以图形与关键字为主，正文用大字号短句。

## 17.5 颜色语义

| 语义 | 用途 | 禁止 |
| --- | --- | --- |
| 密级色 | 材料卡片左上角标识 | 不得用于装饰 |
| 状态色 | 会议状态、设备在线、表决进行中 | 不得同时表达两种含义 |
| 强调色 | 主按钮、当前页 | 同屏不超过 1 处 |
| 危险色 | 删除、熔断、告警 | 不得用于普通按钮 |

颜色不是唯一信息载体：密级同时用文字标签，状态同时用图标，避免色盲用户无法辨识。

## 17.6 组件规范

| 组件 | 规格 | 六端差异 |
| --- | --- | --- |
| 主按钮 | 高 40（触控 44），圆角 8，实心 | TV 无按钮 |
| 材料卡 | 16:9 缩略图 + 标题 + 页数 + 密级 | TV 放大 1.5 倍 |
| 批注气泡 | 最大宽 320，超出折行 | 白板用侧栏 |
| 工具栏 | 底部居中，浮于内容之上 | 白板为左侧竖排 |
| 表决面板 | 三选项纵向，大点击区 | TV 只展示结果 |
| 桌牌 | 姓名 + 职务 + 部门，居中 | 一体机专用 |
| 状态条 | 顶部 4 px 细条，颜色表示状态 | TV 隐藏 |

## 17.7 交互规范

| 端 | 规范 |
| --- | --- |
| 触控 | 最小点击区 44 × 44；间距 ≥ 8 |
| 平板 | 支持双指缩放材料，三指切换页；笔与手指分离（笔画 vs 滚动） |
| 白板 | 笔优先：落笔即画，手掌防误触；橡皮擦区分「擦笔画」与「擦区域」 |
| PC | 键盘可达全部功能；`←/→` 翻页，`空格` 下一页，`Esc` 退出全屏 |
| TV | 无焦点概念，禁止任何需要点击的交互；遥控器只做上下切换议题 |
| 一体机 | 刷卡即签到，3 秒无操作回待机 |

## 17.8 视觉一致性检查

| 检查项 | 方法 |
| --- | --- |
| 令牌覆盖 | 扫描代码中是否出现裸色值（正则 `#[0-9a-f]{3,6}`） |
| 字号阶梯 | 是否使用了非令牌字号 |
| 间距 | 是否为 4 的倍数 |
| 组件变体 | 同一组件是否出现超过 2 种形态 |
| 截图回归 | 六端同屏截图比对，差异像素 < 0.5% |

## 17.9 无障碍

- 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1。
- 焦点可见：键盘焦点必须有 2 px 描边，且不被裁切。
- 动效可关：提供「减少动效」开关，关闭后仅保留 20 ms 淡入。
- 屏幕阅读器：材料页提供「朗读」入口，读文本层而非图片。

## 17.10 交付物

| 交付 | 形式 |
| --- | --- |
| 令牌 | `design-tokens.json` + 生成的 CSS 变量 |
| 组件库 | 代码 + Storybook 示例 |
| 六端截图 | 每个关键界面 × 6 端 |
| 走查记录 | 问题清单与修复状态 |

设计标准的验收不看文档写得多漂亮，只看两件事：**六端截图是否一致**、**代码里有没有绕过令牌的硬编码**。
